# Interview Pal · 让好技术，也能被听见

面向准备外企面试的算法工程师：把熟悉的技术和真实的项目经历，练成清楚、自然的英语表达。

本仓库同时包含**产品规格、页面设计、开发文档和可运行的本地训练应用**。v0.2重点补齐“不会回答时先生成参考”“选择保留本地录音”和“历史追问精确复练”。当前仍是单用户本地训练版本，尚未作为多用户 SaaS 上线。

迁移到本地 ChatGPT / Codex 继续开发，请先看 [本地迁移清单与接手提示词](docs/LOCAL_MIGRATION.md) 和 [开发交接](docs/HANDOFF.md)。

## 快速开始

需要 Node.js **22.12+** 或受支持的更新版本。

```bash
git clone https://github.com/hellen9527/ai_interview_paln.git
cd ai_interview_paln
npm ci
cp .env.example .env
npm run dev
```

访问 **http://127.0.0.1:5173**。没有模型密钥也能整理资料、浏览题库、跟读、录音回听和保存自主练习。

构建后同源运行：

```bash
npm run build
npm start
```

访问 **http://127.0.0.1:3001**。服务只监听本机；当前没有账户鉴权，不应直接公开部署。

验证代码：

```bash
npm test
npm run typecheck
npm run build
```

## 体验路径

1. **建立个人计划**：首次打开有明确标记的示例资料；点击“创建我的计划”清空示例，填写目标岗位、面试日期和 JD。
2. **整理真实经历**：上传 PDF / DOCX / TXT，或粘贴中文要点。逐条确认提取的事实，补充项目背景、职责、选择、结果和反思。
3. **准备英文介绍**：根据确认事实生成稿件，或自行填写；核对后进入逐句跟读、关键词复述与无稿回答。
4. **练技术与项目**：从24个有来源的算法题簇开始。可以先作答再获得反馈，也可以在尚未作答时生成英文参考；待补事实会单独列出，核对并确认后再跟读。
5. **练反问与模拟**：结合目标 JD 练习反问；3 / 5 题模拟隐藏参考表达，保存后统一复盘。
6. **选择保存和复习**：录音默认不保留；主动勾选后可连同练习存入本机IndexedDB，之后回放或下载。历史记录保存实际问题和当时上下文，可以精确重练一条追问；无稿模式仍隐藏旧答案。
7. **备份资料**：JSON备份包含文字资料和记录，**不包含音频**。换浏览器、换端口或跨设备导入不能恢复原浏览器中的录音，请单独下载需要保留的音频。

| 语音 | 浏览器录音、回放、下载；主动选择后本机保留；可选独立ASR         | 发音评测、音素定位、实时通话、云端音频备份     |
| 学习 | 三种模式、辅助标记、逐题模拟、历史问题快照精确复练              | 经人工校准的掌握判定与自适应间隔复习           |
| 数据 | 本浏览器保存、备份/恢复、导出、清除                             | 登录、多用户隔离、跨设备同步、云端持久化、付费 |

**录音保存说明：**单段最多10MB，本应用总量上限100MB，浏览器实际可用配额可能更低。仅在主动选择后保存；保存失败保留页面内容供重试，有文字时可以改为仅存文字。未转写的音频也可作为自主练习保留，但不会被假装分析过。浏览器清理或卸载可能删除本机数据，这不是永久云存储。

**不生成虚假的发音分数。** 文本模型只分析提交的文字；“独立回答候选”不等于口语过关，更不代表拿到 offer 的概率。

## 配置模型

在服务器 `.env` 中填写：

```dotenv
LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
LLM_API_KEY=在本地填写你的密钥
LLM_MODEL=deepseek-flash
```

DeepSeek / Doubao 通过 OpenAI 风格 Chat Completions 接入，具体可用 ID 以服务商账号和官方文档为准。当前研究示例与“开放权重 / 商业 API”的区别见 [MODEL_RESEARCH.md](docs/MODEL_RESEARCH.md)。仓库不包含模型权重，不自动下载或本地运行大模型。

可选语音转写单独配置 `ASR_BASE_URL`、`ASR_API_KEY`、`ASR_MODEL`。这要求服务兼容 multipart `POST /audio/transcriptions`；不能假定文本模型同样支持音频，火山原生语音协议需要另外适配。

密钥不使用 `VITE_` 前缀，不出现在前端输入框、浏览器存储或备份中。不要将真实密钥、简历或录音提交到仓库。

## 验证与上线准备

2026-10-11完成v0.2集成验证：`npm test` **64/64通过**，`npm run format`与`npm run build`通过；构建包含TypeScript检查。分项与边界见 [ACCEPTANCE.md](docs/ACCEPTANCE.md)。模型和ASR的mock协议测试不能证明真实模型效果；React静态渲染和jsdom交互测试不能替代真实浏览器麦克风、IndexedDB配额、媒体播放和移动设备验收。当前没有实际付费模型效果验证，也未将浏览器录音识别或本地保存能力等同于专业语音评分。

公开上线前，优先补充身份认证、服务端授权和存储、用户配额、文档解析隔离、删除流程，以及真实语音设备和模型质量评估。当前生产依赖审计有 3 项中等风险传递依赖（DOCX 处理依赖链 `mammoth → argparse → sprintf-js`），没有高危或严重项；需要持续维护，不使用强制降级掩盖审计结果。
