# Interview Pal v0.2 交付与继续开发

更新日期：2026-10-11。仓库：`hellen9527/ai_interview_paln`，分支：`main`。迁移清单、启动步骤与接手提示词见 [LOCAL_MIGRATION.md](LOCAL_MIGRATION.md)。

## 本轮目标与范围

v0.2延续现有八个页面和本地单用户结构，重点补齐三段真实学习流程：

1. **不会回答也能开始准备**：新增`POST /api/answer`，技术、项目和反问无需先提交答案即可生成英文参考。个人经历缺失信息通过`missingFacts`明示，用户核对、补充或保留诚实未知后确认用稿。生成结果不自动成为个人事实。
2. **选择保留本地录音**：默认不保存。用户主动勾选后，练习录音存入当前浏览器IndexedDB，可在复盘回放、下载或删除。单段10MB、总量100MB；浏览器配额可能更低。未转写录音可作为自主练习保存，但不产生内容或发音结论。
3. **重练当时的那道问题**：保存实际问题及原上下文快照，历史追问可精确复练。当前资料后来修改不影响旧题上下文；无稿模式不展示旧答案和参考稿。原题与不同追问按实际问题区分复习。

保留上一版能力：简历TXT/PDF/DOCX提取、事实确认、项目五维编辑、JD保存、24个题库种子、三种练习模式、逐题模拟、反馈与备份。所有题库种子仍待专家复审。

## 运行与配置

以根目录README和`DEVELOPMENT.md`为准。Node 22.12+，`npm ci`，复制`.env.example`为`.env`：

- 开发：`npm run dev`，访问`http://127.0.0.1:5173`。
- 构建与本地使用：`npm run build`后`npm start`，访问`http://127.0.0.1:3001`。
- 检查：`npm test`、`npm run typecheck`、`npm run build`。

`.env`只留在本地。LLM和ASR分别配置，没有密钥仍可自主练习。API继续只接受本机访问；本轮没有放开公网权限。

## 录音、备份与失败处理

| 情况                       | v0.2行为                                                             |
| -------------------------- | -------------------------------------------------------------------- |
| 未勾选保留录音             | 仅在当前页面回放，离开后不能从历史找回                               |
| 主动选择并保存成功         | IndexedDB保存Blob，文字记录保存本地音频引用                          |
| 音频存储失败               | 不追加完整尝试；保留页面Blob和文字，允许重试；有文字才提供仅文字保存 |
| 未转写音频                 | 可保存自主练习，不显示伪造文字和评价                                 |
| JSON导出                   | 不包含音频本体，也不包含API Key                                      |
| JSON导入                   | 仅保留当前浏览器仍存在的音频引用；不会自动删除其他本机录音           |
| 跨设备导入                 | 无法恢复原浏览器中的音频；需要用户单独下载保存                       |
| 删除有音频的记录           | 先成功删除对应本地音频，再删除文字记录；失败需明确说明               |
| 清空所有资料               | 音频清理失败时不能显示全部删除成功                                   |
| 原地恢复或多次导入留下音频 | 在设置中查看占用并清理未关联录音                                     |

localStorage与IndexedDB均按浏览器来源隔离，5173和3001的资料也不同。浏览器清理、隐私模式和设备丢失都可能造成数据丢失；本地保留不是云端备份或永久保存。

## 历史兼容规则

- 新记录有上下文快照：按实际问题和原快照开始练习，保留原题的相关事实及评估背景。
- 旧记录只有实际问题：可以复现问句，但不拿当前项目事实或参考答案冒充历史背景；界面说明上下文缺失。
- 旧记录连问题也没有：明确回到原题主题，不能称为精确复练。
- 无稿开始不预填上次答案，参考稿也不放在可展开的隐藏DOM里；主动请求辅助后才显示并记录辅助使用。

## 当前实现的具体限制

- JD最多保存12,000字符。反问的`/answer`可使用完整JD；既有`/feedback`只附加前3,000字符，生成下一问的上下文整体上限20,000字符。暂未做长JD语义检索或自动摘要。
- 回答保存与内容评估入口最多15,000字符；ASR输出可能更长，需用户精简后再保存。参考稿上限8,000字符。
- `missingFacts`、事实ID检查与项目数字保护是辅助约束，不能证明所有语义均真实。用户仍须核对职责、成果、技术选择与假设措辞。
- 历史快照保留问题所需的项目与岗位背景；不是完整档案版本库。资料更新后的所有稿件依赖追踪、选择性级联删除仍待实现。
- 音频与文字分属IndexedDB和localStorage，尚无跨库原子事务。文字持久化失败会提示；可能遗留的未关联音频可在设置清理。

## 仍未实现的生产能力

账户鉴权、多用户权限隔离、服务端学习记录、跨设备音频同步、支付计费、专业发音评测和实时语音通话均不在本轮。CORS、Host检查和本地IndexedDB不能替代这些能力。

内容与学习方面仍需专家题库审核、真实模型质量与成本基准、真实听懂率及迁移复测校准。本地录音可回放不等于发音已被评价，也不意味着已经达到“80分过关”。
